# Memory as Phase Transition: Discrete Shifts, Not Gradual Accumulation

**Sources:**
- arXiv:2605.17199 — "Geometric Phase Transition Enables Extreme Hippocampal Memory Capacity" (2026)
- PNAS 2026 — "A J-domain protein enhances memory by promoting physiological amyloid formation in Drosophila" (Si Lab, Stowers Institute)

**Date discovered:** 2026-08-31

## The Core Finding

Two independent 2026 results converge on the same structural claim: **memory formation is a discrete phase transition**, not gradual accumulation.

## Finding 1: Hippocampal Geometry (arXiv:2605.17199)

Food-caching chickadees vs non-caching zebra finches: 100-fold difference in spatial memory capacity (1000+ locations vs <10) traces to a discrete structural reorganization of neural population codes.

- "Disorganized mist" → "crystalline" geometry (discontinuous transition)
- Crystalline codes require **169-fold representational redundancy** as a "geometric tax" for stability against biological noise
- Superior memory correlates with near-zero split-half allocation reliability — geometric, not anatomical specialization
- Validated via Valiant's Stable Memory Allocator + 10,000 computational configurations

The capacity gain comes from geometric stability, not neuron count. Evolution engineers memory through neural code geometry.

**Connection to grokking:** Same discontinuous transition — disorganized/memorizing → organized/generalizing. Both are "suddenly" not "gradually." See topics/grokking-phase-transitions.md.

## Finding 2: Functional Amyloids — Funes and Orb2 (PNAS 2026)

Long-term memory in Drosophila requires Orb2 (prion-like protein, related to mammalian CPEB) to transition from soluble state to **amyloid fibers at specific synapses**. The chaperone Funes regulates this. Without Funes triggering Orb2's amyloid transition, long-term memory fails entirely.

Published: Stowers Institute, Si Lab, PNAS January 30, 2026.

## The Borges Irony

The researchers named the chaperone **Funes** after Borges' "Funes the Memorious" (1942). Funes the character acquires perfect eidetic memory after a fall — he remembers every detail of every moment in exact fidelity. But he cannot abstract: *"to think is to forget differences, generalize, make abstractions. In the world of Funes, there were nothing but details, almost contiguous details."* He dies at 21, crushed by particularity.

The biological Funes solves the Borgesian problem rather than embodying it:
- **Selective**: acts only at specific synapses, triggered by specific experiences
- **Committing**: once Orb2 goes amyloid, the memory is structurally set
- **Non-total**: enables recall of what matters, not total crystallization of everything

The scientists named the protein for the obvious connection — memory. The deeper irony is that the protein does what the character could not: filter.
